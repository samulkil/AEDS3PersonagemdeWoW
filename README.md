# AEDS3PersonagemdeWoW
CRUD Para organizar personagens de Jogos
Como Testar a Compactação:
Siga as instruções abaixo para realizar os testes dos algoritmos e verificar a geração dos arquivos de compactação:
•	Execute o programa principal:
python main.py
•	No menu principal, escolha a opção de backup 
•	Selecione 7 para Fazer Backup Compactado (Huffman + LZW)
•	Aguarde a mensagem de sucesso, o programa deve informar os caminhos de
backup_huffman.bin
backup_lzw.bin
•	Verifique os arquivos gerados:
backup_huffman.bin
backup_lzw.bin
